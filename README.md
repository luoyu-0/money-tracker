# Money Tracker

使用 Flutter 构建的 Android 和 iOS 个人记账本。安装后即可离线记录人民币收支和查看统计。用户可以手动备份账本、导出和导入记录，也可以主动请求 AI 月度总结与规划建议。界面使用简体中文。

首版产品和技术范围已定稿，仓库当前提供设计与验收文档。
