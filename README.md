# Money Tracker

Money Tracker 是一款面向 Android 和 iOS 的轻量个人记账本。用它记录人民币收入和支出，按时间查看收支变化和分类构成。核心记账和统计支持离线使用，界面采用简体中文。

**当前状态**　首版设计已定稿，应用尚未提供可安装版本。以下为首版计划提供的使用方式。

## 使用方法

1. **记一笔**　在「账本」点击「记一笔」，选择收入或支出，填写金额并选择来源或用途。可以添加自定义候选值，也可以补充交易对方。日期默认当天，可按需修改。
2. **查看收支**　在「统计」查看当前月份的收支趋势、分类构成和时段对比。支持切换本周、本月、本年和自定义日期。
3. **生成月度分析**　在「设置」选择 DeepSeek、千问或 GLM，并保存该服务商的 API Key。进入月度分析，选择月份并点击生成。此功能需要联网。
4. **备份或换机**　在「设置」创建整本备份，换机后选择该文件恢复。仅需转移部分账目时，按日期导出记录，再在目标设备导入。
