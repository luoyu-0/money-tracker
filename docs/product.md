# 产品需求

## 产品定位

面向个人使用的轻量记账本。用户能方便地记录资金收支，也能回顾一段时间内的钱从哪里来、花到哪里去。

## 已确认的首版范围

| 能力 | 目标 |
| --- | --- |
| 记账 | 以手动快速录入为主，录入收入或支出、金额、来源或用途、可选交易对方和日期。 |
| 统计 | 离线查看收支趋势、分类构成、两个时段的对比，以及收入与支出的对比。 |
| 数据 | 本机保存账本，支持手动备份恢复和本应用记录的导出导入。 |
| AI 分析 | 用户主动触发，按月生成收支总结和规划建议。 |
| 设置 | 提供清除缓存与清除本机数据的入口，以及 AI 服务商和 API Key 配置。 |
| 客户端 | 使用 Flutter，支持 Android 和 iOS。 |
| 语言和币种 | 界面仅使用简体中文，账目仅使用人民币。 |

## 账目字段

| 字段 | 要求 |
| --- | --- |
| 类型 | 收入或支出。 |
| 金额 | 人民币金额。 |
| 来源或用途 | 收入填写来源，例如「工资」。支出填写用途，例如「餐饮」。 |
| 交易对方 | 可选。收入填写发钱方，支出填写收钱方。 |
| 发生日期 | 默认记账当天，用户可修改。 |

首版账目以这五个字段为录入模型。分类构成按来源或用途汇总。例如「餐饮」是用途，「某餐馆」是交易对方。

来源或用途提供按收支类型分组的候选值。收入可选「工资」等内置来源，支出可选「餐饮」等内置用途。用户可以在记账时添加自定义候选值，并用于当前和后续账目。保存时去掉候选值首尾空白，同一收支类型内的同名值只保留一项。账目保留保存时所选的值，统计按收支类型和保存的值归组。

历史账目可编辑，经确认后可删除。保存或删除成功后，账目和统计应反映最新结果。

## 统计

默认显示本月，主周期可切换本周、本月和本年。首版图表包括收支趋势、分类构成、前后月或其他时段的对比，以及当前所选时段的收支对比。

- 本周从周一开始，日期筛选包含显示的起止日期。补录和编辑日期决定账目进入哪个统计区间。
- 自然周期默认与上一自然周期比较。当前周期未结束时按相同已过天数截取上一周期，上一周期天数不足时以其末日为界。
- 可手动指定对比日期，两段区间分别显示起止日期。收入、支出和结余统一按同一日期口径计算，结余为收入减去支出。

## 使用与验收

安装后即可使用核心功能。账目通过手动录入或导入本应用文件获得。参见 [数据与迁移](data-portability.md) 和 [AI 月度分析](ai-analysis.md)。

Android 使用现有真机通过无线调试验收。iOS 仍是目标平台，目前没有 iOS 真机，实际构建和模拟器验证取决于 macOS 与 Xcode 环境。

页面布局、录入反馈和动效细节见 [界面与交互](interface-design.md)。
