# 数据与迁移

## 已确认

账本保存在本机，记账与统计支持离线使用。用户主动执行以下文件操作。

| 操作 | 用户目的 |
| --- | --- |
| 备份与恢复 | 保存账本副本，换机或重装后可以恢复。 |
| 记录导出与导入 | 导出本应用记录，可以将该文件导入本应用。导入来源限定为本应用生成的记录文件。 |

## 备份与账目交换

- 备份和记录导出使用带版本的 JSON，由文件标识区分用途。
- 备份包含账目、自定义候选值和 AI 报告。恢复先校验并预览，用户确认后整体替换这些内容，并将恢复前的状态保存为副本。校验或写入失败时保留原账本。设备设置和 API Key 继续使用恢复前的值。
- 记录支持按日期范围导出。导入预览显示新增、重复和冲突的数量，确认后合并新增记录。
- 记录文件保留各条账目的来源或用途，导入后直接参与统计。候选值列表的迁移通过整本备份完成。
- 导入使用稳定的记录标识。相同标识且内容相同的记录跳过。相同标识但内容不同的记录视为冲突，保留本机版本并提示。不同标识的同日同额记录可以各自存在。

## 清理入口

- **清除缓存** 删除可重建的应用缓存和临时文件。
- **清除本机数据** 在确认页列出影响范围，并提供进入备份的入口。确认后删除账目、自定义候选值、AI 报告、设置、API Key、缓存和临时文件，应用回到初装状态。已经保存到应用外的备份和导出文件保留。
