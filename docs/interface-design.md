# 界面与交互

首版以「账本」为打开应用后的默认页面。用户可以单手快速补上一笔，也可以回看哪类收入或支出发生了变化。以下为首版视觉与动效的设计基线，具体尺寸和时长可在 Android 真机上微调。

## 视觉样式

- 采用白底、浅蓝和蓝灰墨色的账簿样式。让结余区和实际数据图表承担视觉重点，最近账目用细分隔线连续排布。
- 页面底色 `#F4F8FD`，内容表面 `#FFFFFF`，强调底色 `#E0EEFF`。主操作采用深蓝 `#215BA5` 配白字。账目用金额正负号、语义色和读屏标签表达收支，行内只显示账目名称、可选交易对方和金额。
- 中文使用系统无衬线字体。金额使用等宽数字特性，保留人民币符号与必要的小数位。账本页的大字优先给周期总额，列表金额与同组记录对齐。窄屏或系统大字体时允许标签换行。
- 页面复用金额组件、日期范围控件、候选值按钮和反馈样式。表单、日期选择、确认框和文件选择沿用平台熟悉的交互。

## 页面与操作

| 入口 | 首屏内容 | 关键反馈 |
| --- | --- | --- |
| 账本 | 此月结余、收入与支出、按日期分组的记录、固定位置的「记一笔」。 | 首次打开显示真实空账本，并提供「记第一笔」。点击记录打开编辑。 |
| 记一笔 | 从底部打开录入面板，金额与收支类型优先。随后选择来源或用途，可在原处添加候选值。交易对方和日期放在金额下方。 | 默认当天，保存成功后返回账本并突出新增行。校验失败时保留已填内容，在相应字段旁给出原因。 |
| 统计 | 周期切换、当前日期范围、结余变化摘要和对比表，下方是趋势、分类构成和 AI 分析入口。 | 摘要从上一周期同期结余指向本周期结余。趋势用双折线，分类用环形图及金额排行。 |
| 月度分析 | 月份、已存报告和「生成月度分析」。发送前可查看实际汇总内容。 | 显示所选服务商与请求状态。缺少 Key 时提供设置入口，失败时保留可阅读的历史报告。 |
| 设置 | AI 服务配置、账本备份、记录导入导出、清除缓存和清除本机数据。 | 恢复和清除本机数据的确认界面明确列出影响，文件操作显示预览、结果和失败原因。 |

底部导航使用「账本」「统计」「设置」三个入口，支持点按和横向拖动页面，保留各页的滚动和筛选状态。录入面板直接使用系统键盘上报的可用区域，当前字段和保存动作可通过滚动到达。

## 数据展示

- 账本摘要的收入和支出分列左右边缘。结余的变动以本月至今和上个完整自然月比较，计算为「差额 ÷ 上月结余绝对值」。上月无账目或结余为零时显示「—」。
- 折线图使用日期横轴、人民币金额纵轴和收入／支出图例。统计图隐藏点划线网格。分类环加宽并使用圆角扇环，图例的名称、金额和占比各列左对齐。
- 对比表逐行显示收入、支出和结余，各列为项目、本周期、上一周期同期和变动。本周期收入用绿色、支出用红色。变动用正负号表示增减，收入或结余增加、支出减少用绿色，反向变化用红色，持平用中性色。
- 月度报告的月份选择按三行四列排列无边框圆形数字，选中月份使用更深的蓝色底，辅助技术朗读完整月份。
- 模型服务商菜单在表单字段下展开，沿用界面的圆角、细边线和蓝色选中底。

## 动效

| 场景 | 设计基线 |
| --- | --- |
| 打开记账 | 面板从底部进入，约 240 ms。收起约 180 ms，结束后焦点回到原入口。 |
| 切换收入／支出 | 文字保持固定字重与收支语义色，由同色滑块表示选中状态。滑块与内容同步移动，容器高度随行数过渡。连续切换时沿当前进度反向，金额和交易对方的输入状态保留。 |
| 切换统计周期 | 本周、本月和本年共用单一滑块，选中反馈由滑块位移承担。新日期区间直接绘制对应坐标，避免跨不同日期轴插值。 |
| 点击主要按钮 | 小幅降低高度并以表面高光反馈按压。重点卡片用表面由亮到暗的光线、圆角和向下的柔和投影表现浮起感。 |
| 切换主导航 | 手势过程中页面跟随手指，松手后吸附。点按导航时，页面用先慢后快的平移切换。 |
| 保存账目 | 写入成功即更新列表，新增行背景短暂淡出，约 240 ms。金额立刻显示最终值。 |
| 切换日期范围 | 保持图表区域稳定，约 180–240 ms 过渡到最新数据。连续切换时以最后一次选择为准。 |
| 生成 AI 报告 | 请求期间显示清晰状态。成功后以约 180 ms 淡入新增报告，失败时同位置提供重试。 |

遵循系统的减少动态效果设置，将位移和图形插值改为即时更新。动效与数据写入解耦，页面返回和重新选择都可立即响应。

## 真机验收

- 首次启动可直接用内置候选值完成第一笔账目。记账时新建的候选值可立即选用，下次打开仍可选择。
- Android 小屏和系统大字体下，测试键盘升降、候选值换行、日期选择、底部安全区，以及长交易对方名称和大额金额。
- 图表提供可读的期间、数值和图例。文字与底色对比至少 4.5:1，常用触控区域至少 48 × 48 逻辑像素。用 TalkBack 验证账目、操作和图表摘要的朗读顺序。
- 连续切换周期、快速录入和返回、系统减少动态效果等场景保持响应。图表过渡和长列表滚动在 Android 真机上检查掉帧情况。
